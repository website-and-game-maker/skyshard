# Skyshard

A 3D platformer that runs in the browser. Guide Pip, a small sky spirit, across floating islands, collect shards, and relight the beacon.

Plays on desktop (keyboard and mouse), phones and tablets (touch), and with a gamepad. Every model, texture and sound is generated in code.

## Run it
```
npm install
npm run dev
```

## Check it
```
npm test          # unit tests
npm run build     # production build in dist/
npm run test:e2e  # browser tests
```

Feedback from the title or pause menu goes to the Unblock Games inbox. Inside the arcade it opens the arcade's own report dialog, so there is one Feedback button, not two.

See `CONTRACTS.md` for how the code is split up.
